# Airbnb Listings and Reviews Analysis | Power BI

**Project Type:** Practice Project
**Dataset Source:** Maven Analytics
**Tools:** Power BI, Power Query, DAX

## Project Objective

Analyse Airbnb listings and reviews across 10 cities to understand property distribution, pricing, customer ratings, host verification, and seasonal review patterns.

## Key Analytical Findings

* Analyzed 279,712 listings across 10 cities.
* Paris, New York, and Sydney collectively represent 48.38% of listings.
* Mexico City and Rio de Janeiro recorded strong ratings across multiple evaluation dimensions.
* Approximately 66.9% of the host records in the trust analysis fall into the verified-with-profile category.
* Paris and Rome account for significant review activity across much of the year.

## Technical Skills Demonstrated

* Data modeling and table relationships
* DAX measures using CALCULATE, FILTER, ALL, ALLEXCEPT, and DIVIDE
* Cumulative percentage calculations
